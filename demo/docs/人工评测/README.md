# 人工评测表怎么用

两张表都由 `python scripts/make_eval_sheet.py` 生成（默认每工程 12 条功能条目、6 条报告结论）。

1. **功能命名与摘要.csv**：看「功能名」「摘要」是否说对了这段代码在做什么；
   「证据」列给出入口方法与行号，可点开 `代码结构` 页对应文件核对。
2. **报告结论.csv**：看「原文」这条结论是否成立；「能否回指源码(自动)」只是正则判断，
   结论多数是统计量（如社区数、矩阵单元格），本来就无法回指到某一行，以「判定」为准。

判定列只填三个值：`对`、`部分`、`错`（留空表示跳过）。填完运行：

```bash
python scripts/score_eval_sheet.py
```

会打印两张表的准确率（部分按 0.5 计），并把结果写到 `docs/人工评测/结果.json`。
把这组数字抄进论文「方法评测」一节，替换现在的「规则判定」口径即可。
